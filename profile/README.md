# MONSTER Lab · Luo Group, University of Notre Dame

Code and data from Prof. Tengfei Luo's group (Aerospace and Mechanical Engineering, University of Notre Dame). We combine AI, physics-based simulation, and autonomous experiments to discover and understand materials, with a focus on polymers and thermal transport.

Website: https://monsterlab.nd.edu

## Materials informatics

| Repository | What it does |
|---|---|
| [PI1M](https://github.com/RUIMINMA1996/PI1M) | Benchmark dataset of about one million hypothetical polymers for polymer informatics |
| [POINT2](https://github.com/tengfeiluo/POINT2) | POINT2: polymer informatics training and testing benchmark, with code and fixed data splits |
| [ADEPT](https://github.com/sobinalosious/ADEPT) | Automated molecular dynamics engine for polymer simulations |
| [PolyGraphMT](https://github.com/sobinalosious/PolyGraphMT) | Multi-task, multi-fidelity graph learning for polymer properties |
| [PolymerBlendTC-ActiveLearning](https://github.com/Jiaxin-Xu/PolymerBlendTC-ActiveLearning) | Active learning to find polymer blends with high thermal conductivity |
| [POLY-CP-TL](https://github.com/sobinalosious/POLY-CP-TL) | Transfer learning for polymer specific heat capacity |

## Self-driving labs

Robotic and agentic platforms for autonomous materials experiments.

| Project | What it does | Links |
|---|---|---|
| Frugal-twin SDL for thermoresponsive polymers | Low-cost self-driving lab that mixes, heats, and measures, and uses Bayesian optimization to tune the lower critical solution temperature of PNIPAM | [Paper (*Adv. Intell. Discov.*, 2026)](https://doi.org/10.1002/aidi.202500177) · [arXiv](https://arxiv.org/abs/2509.05351) · [Code](https://github.com/An-xu/SDL_LCST_OP) |
| LabApprentice | A coding agent drives a robot arm and existing bench instruments, and reuses the tools it writes across wet-lab tasks (CoRL 2026 Late-Breaking Results) | [Project page and experiment videos](https://jill0001.github.io/LabApprentice/) |
| ProtoAsk-VLA | Protocol-aware robot execution that asks for human help only when a proposed action may violate a lab protocol (IROS 2026 SDL workshop, with the Hou group) | [Project page and videos](https://sites.google.com/view/protoask) |

Undergraduate senior design teams are also building autonomous instruments, including an automated differential scanning calorimetry station and a liquid mixing and heating system for ionic liquids.
